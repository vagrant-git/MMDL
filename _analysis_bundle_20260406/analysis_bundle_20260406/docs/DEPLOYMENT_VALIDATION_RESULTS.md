# 部署验证结果

验证环境基于当前板端部署包 `rk3588_bundle/`，模型为 `hcaf_pcen_dualxattn.onnx`。  
验证数据来自 `board_test_sessions/`。

## 1. 推理一致性验证

验证集：`board_test_sessions/smoke/`  
窗口设置：`5 s` 窗口，`5 s` hop

对比路径：
- 参考路径：`audio.wav` 从 `22050 Hz -> 16000 Hz`，DAQ 保持 `100 Hz`
- 板端模拟路径：音频 `22050 Hz -> 44100 Hz -> 16000 Hz`，传感器 `100 Hz -> 10 Hz -> 100 Hz`

总体结果：
- 总窗口数：`362`
- 参考路径与板端模拟路径窗口级预测一致率：`362 / 362 = 100%`
- 最大概率差异：`0.02897`
- 最大 logits 差异：`2.11652`

各 session 结果：

| Session | 期望标签 | 参考路径多数预测 | 板端路径多数预测 |
|---|---:|---:|---:|
| `MMdata_235.00s_0320_224031_no_secretion` | `0` | `4` | `4` |
| `MMdata_1136.50s_0327_183428_2ml` | `2` | `4` | `4` |
| `MMdata_442.75s_0327_203239_4ml` | `4` | `4` | `4` |

结论：
- 部署链路一致性通过。
- 当前板端重采样路径不会引入额外预测漂移。
- 但当前模型在这批 `smoke` 样本上的类别输出明显偏向 `4`，因此“一致性通过”不等于“样本标签准确率通过”。

## 2. 实时性 / 资源占用验证

验证集：`board_test_sessions/benchmark/`  
窗口设置：`5 s` 窗口，`1 s` hop

总体结果：
- 总窗口数：`1929`
- 平均 session 推理时延：`117.08 ms`
- 最差 session 的 `p95` 时延：`177.65 ms`
- 最差单窗口时延：`218.97 ms`
- 吞吐：`8.42 windows/s`
- 相对 `1 s` hop 的实时因子：`0.178`
- 最大 RSS：`284.71 MiB`

各 session 结果：

| Session | 期望标签 | 多数预测 | 是否匹配 | 平均时延(ms) | p95(ms) |
|---|---:|---:|---|---:|---:|
| `MMdata_1071.50s_0327_201445_4ml` | `4` | `4` | `是` | `120.06` | `177.65` |
| `MMdata_272.75s_0327_174501_2ml` | `2` | `4` | `否` | `113.05` | `174.44` |
| `MMdata_598.25s_0322_224923_no_secretion` | `0` | `4` | `否` | `118.13` | `174.45` |

结论：
- 实时性通过，当前板端推理速度明显快于 `1 s` hop 的实时要求。
- 资源占用可控，当前最大常驻内存约 `284.71 MiB`。
- 目前的主要问题不在部署速度，而在模型对 `0/2` 类样本的输出偏移。

## 3. 最终结论

最终可给出的两个结果如下：

1. 推理一致性验证：通过。  
   板端采集与重采样链路不会破坏模型推理一致性，参考路径与板端模拟路径窗口级预测一致率为 `100%`。

2. 实时性 / 资源占用验证：通过。  
   当前部署在 `1 s` hop 条件下具有明显实时余量，最差 `p95` 时延约 `177.65 ms`，最大 RSS 约 `284.71 MiB`。
