# Board Test Sessions

这个目录是给小主板验证用的推荐测试集，单独从 `data/` 中挑出来，避免整库全拷。

## 目录结构

- `smoke/`
  - 用于首轮推理一致性验证
  - 目标是先确认板端结果和 PC 侧一致
- `benchmark/`
  - 用于后续实时性、资源占用和稳定性验证
  - 目标是补充长时长样本和不同类别覆盖

## 1. smoke

### `MMdata_235.00s_0320_224031_no_secretion`

- 类别: `0`
- 用途: 第一个 smoke test
- 特点: 文件较短，拷贝快，当前模型预测稳定

### `MMdata_1136.50s_0327_183428_2ml`

- 类别: `2`
- 用途: 验证中间类别
- 特点: 当前模型预测稳定，适合做一致性对比

### `MMdata_442.75s_0327_203239_4ml`

- 类别: `4`
- 用途: 验证高类别
- 特点: 当前模型预测非常稳定

## 2. benchmark

### `MMdata_598.25s_0322_224923_no_secretion`

- 类别: `0`
- 用途: 补充更长一点的 `0` 类样本

### `MMdata_272.75s_0327_174501_2ml`

- 类别: `2`
- 用途: 补充较短 `2` 类样本

### `MMdata_1071.50s_0327_201445_4ml`

- 类别: `4`
- 用途: 补充较长 `4` 类样本

## 3. 推荐使用顺序

1. 先在板子上只拷 `smoke/`
2. 先做推理一致性验证
3. 如果 `smoke/` 三类都对齐，再加入 `benchmark/`
4. 再做实时性、资源占用和稳定性测试

## 4. 最小建议

如果你只想先做最小验证，优先用：

- `smoke/MMdata_235.00s_0320_224031_no_secretion`
- `smoke/MMdata_1136.50s_0327_183428_2ml`
- `smoke/MMdata_442.75s_0327_203239_4ml`
